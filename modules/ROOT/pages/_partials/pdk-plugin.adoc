[[policy-project-create]]
== policy-project:create

----
> policy-project:create [flags] <name>
----

Creates a custom policy definition project with the name specified in `<name>`

This command scaffolds a new project structure for developing a custom MuleSoft policy using the Policy Development Kit (PDK).

This command accepts the xref:index.adoc#default-options[default flags].
